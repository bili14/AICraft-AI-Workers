# AICraft — 让 AI 自己玩 Minecraft

开一个 Minecraft 世界，几个 AI 工人自己进去砍树、挖矿、盖房子、互相聊天。你不用亲手操作任何一个角色，只负责当监工：开世界、配大脑、看它们干活。

Windows 绿色免安装，自带运行环境，不需要另外装 Java、Node，也不需要正版账号。

---

## 它到底是什么

不是游戏，也不是外挂。它是一个**观察 AI 干活**的沙盒：

- 每个工人背后是一个大模型（通义千问 / DeepSeek / 火山方舟 / Agnes，任选）
- 工人每隔十来秒思考一次，自己决定下一步做什么，然后真的在游戏里执行
- 多个工人共享一个世界，会分工、会让路、会在公屏上聊天
- 你可以随时用 Minecraft 客户端连进来，和它们同场干活

## 工人会什么

| 类型 | 会做的事 |
|---|---|
| 采集 | 砍树、挖矿、捡掉落物 |
| 建造 | 按蓝图一格一格搭房子（不是瞬间生成的） |
| 搬运与交换 | 把材料丢给队友、用兑换点换资源 |
| 社交 | 公屏聊天、报进度、互相喊话 |
| 自保 | 天黑回屋、躲避危险、死亡后重新出发 |

## 三步跑起来

1. **双击 `AICraft.exe`**（在 `app\electron-dist\` 里；第一次建议先双击根目录的 `创建桌面快捷方式.bat`）
2. **填一把大脑钥匙**：进「AI 大脑供应商」，选一家服务商，粘贴 API Key，点「测试连接」
3. **开世界、开工人**：指挥大厅点「启动服务器」，等世界生成完，再点工人卡片上的「启动」

详细步骤见 [docs/使用说明书.md](docs/使用说明书.md)。

## 你需要准备

- Windows 10 / 11，64 位
- 至少 4 GB 空闲内存（默认两个工人 + 服务器约 2.9 GB，每个 3D 窗再加约 0.3 GB；界面左下角有实时估算条）
- 一个能用的模型 API Key（新账号一般都有免费额度）
- 想亲自进游戏玩的话，再装一个 Minecraft **1.21.4** 客户端

## 界面有七页

| 页面 | 干什么 |
|---|---|
| 指挥大厅 | 开服/停服、看每个工人的实时状态、开 3D 和思考流 |
| 工人对话 | 所有工人的公屏聊天记录 |
| 存档管理 | 看当前世界真身、存一份、删除这个世界重新生成、挑一份存档回到过去 |
| 设置 | 种子/难度/游戏模式/运行内存/死亡不掉落、记忆轮数、端口 |
| AI 大脑供应商 | 配 Key、测连接、拉模型清单、给每个工人选大脑 |
| 工人管理 | 加人、删人、改人设与功能 |
| 帮助 | 常见问题、日志在哪、怎么连进来玩 |

## 关于存档

- 世界只有一个，系统每 10 分钟自动存一份快照，保留最近 5 份
- 你可以随时手动存一份，**服务器开着关着都能存**
- 点「删除这个世界（重新生成）」会**先自动存一份再删**，删完按设置里的种子重新生成
- 点某份存档的「用这个」就能回到那一刻；恢复前也会先给现在存一份

## 常见问题（摘要）

| 现象 | 原因 |
|---|---|
| 双击没反应 / 闪退 | 文件夹没解压完整，或把 exe 单独拖出来了 |
| 弹蓝色「Windows 已保护你的电脑」 | 没签名的小工具常见，点「更多信息」→「仍要运行」 |
| 工人不动 | 额度用完、Key 填错、或服务商限流，看报错码 |
| 卡顿 / 风扇狂响 | 3D 窗开太多，关几个 |
| 改了难度没变化 | 保存后要重启服务器才生效 |

完整对照表见 [docs/使用说明书.md](docs/使用说明书.md)。
