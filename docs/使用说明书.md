# AICraft 使用说明书

> 这份说明是写给**完全没接触过**的人的。不需要懂编程，不需要懂 Minecraft，照着一步一步做就行。
> 全程大约 15 分钟能跑起来，其中大部分时间是在等世界生成和申请 Key。

---

## 0. 先说清楚这是个什么东西

你在电脑上开一个 Minecraft 世界，然后放几个"AI 工人"进去。它们由大模型驱动，会自己决定去砍树、挖矿、盖房子、跟队友说话。

**你不需要操作任何一个角色。** 你要做三件事：

1. 开世界
2. 给工人配"大脑"（一个 API Key）
3. 看着它们干活，或者自己也进游戏一起玩

---

## 1. 开始前要准备什么

### 1.1 电脑

- Windows 10 或 Windows 11，**64 位**
- 至少 **4 GB 空闲内存**（一个工人加服务器大约占 2.9 GB；每多开一个 3D 窗，再加约 0.3 GB）
- 硬盘留出 2 GB 以上空间（世界会随着玩的时间变大）

### 1.2 一个 API Key

这是工人的"大脑钥匙"。没有它，工人不会动。

四个平台任选一个，注册后一般都有免费额度：

| 平台 | 大概怎么拿 |
|---|---|
| 阿里云百炼（通义千问） | 搜"阿里云百炼"进控制台 → 实名 → 「API-KEY」页面 → 创建 → 复制 |
| DeepSeek | 搜"DeepSeek 开放平台" → 注册 → 「API keys」→ 创建 → 复制 |
| 火山方舟（豆包） | 搜"火山方舟"进控制台 → 开通 → 「API Key 管理」→ 创建 → 复制 |
| Agnes | agnes-ai.cn 注册后在控制台拿 Key |

> 网址和界面会变，找不到就用搜索引擎搜平台名字，进官网控制台找"API Key"。
> **Key 就相当于银行卡密码，别发给别人，别截图发群。**

### 1.3 一个 Minecraft 客户端（可选）

只有想**自己进游戏**和工人一起玩才需要。版本必须是 **1.21.4**。
不想进游戏也完全能玩，界面里能看文字和 3D 画面。

## 2. 第一次打开

### 2.1 放在哪里

把整个 AICraft 文件夹放在一个**路径短、没有中文和空格**的地方，比如：

```
D:\Games\AICraft
```

不要放在：
- 桌面（路径长，容易出怪问题）
- 微信/QQ 的下载缓存目录
- C 盘根目录（可能没权限）

> 如果你拿到的是压缩包，先**完整解压**再打开。不要直接在压缩包里双击运行。

### 2.2 双击哪个文件

有三种方式，任选一种：

| 方式 | 操作 |
|---|---|
| 推荐 | 双击 `创建桌面快捷方式.bat`，桌面会多一个图标，以后双击图标 |
| 也行 | 双击根目录的 `AICraft启动.bat` |
| 直接 | 进入 `app\electron-dist\` 双击 `AICraft.exe` |

⚠️ **不要把 `AICraft.exe` 单独拖出来**。它必须和旁边的 `.dll` 等文件待在一起，单独拿出来会打不开。

### 2.3 弹出"Windows 已保护你的电脑"

这是 Windows 对所有"没有花钱买签名证书"的软件的通用提示，不是中毒。

点左边的「**更多信息**」，再点「**仍要运行**」。

### 2.4 杀毒软件拦截

有些杀毒软件会拦 `Java` 或 `Node`（这两个是游戏服务器和工人要用的，程序自带）。

如果被拦：把整个 AICraft 文件夹加入杀毒软件的**信任列表 / 白名单**。

### 2.5 你会看到什么

先出现一个加载画面（会滚动显示一些小提示），几秒后进入主界面。

左边一列是菜单：指挥大厅 / 工人对话 / 存档管理 / 设置 / AI 大脑供应商 / 工人管理 / 帮助。
顶部右上角可以在「暗色」「亮色」之间切换。

如果第一次打开，会自动弹出**新手向导**，跟着它填一遍也行。

---

## 3. 配大脑（这一步最关键）

### 3.1 进「AI 大脑供应商」

点左边的「AI 大脑供应商」。

你会看到几张卡片，每张是一个平台（Agnes、通义千问、DeepSeek、火山方舟）。卡片上有：

- **网址**：这个平台接收请求的地址，一般不用改
- **钥匙**：粘贴你的 API Key
- **型号**：具体用哪个模型

### 3.2 填 Key

1. 找到你申请了 Key 的那张卡片
2. 把 Key 粘贴进「钥匙」框
3. 点「**测试连接**」

看到绿色的"已通"，就说明 Key 能用、网络也没问题。

如果红了，先看提示：
- 「钥匙不对」→ Key 复制不完整，重新复制一次（注意别多带空格）
- 「余额/额度用完」→ 去平台充值或换一个账号
- 「连不上」→ 检查网络，或者公司网络把外网挡住了

### 3.3 选型号

卡片里「型号」下拉能选这个平台支持的模型。**不确定选哪个就用默认的那个**（通常是 `agnes-2.5-flash`、`qwen-plus` 这类便宜快速的）。

点「＋ 添加供应商」旁边的刷新/获取按钮，可以把这个平台最新的模型列表拉下来。

### 3.4 给工人分配大脑

「工人管理」里，每个工人可以选：

- **共用**：所有工人用同一把 Key（简单，适合按量付费）
- **独立**：每个工人用自己的 Key（适合拿多个免费账号薅额度）

新手直接用默认的"共用"就行。

> **想接自己电脑上跑的模型？** 进「AI 大脑供应商」点「＋ 添加供应商」，把你本地服务的完整地址填进去（例如 `http://127.0.0.1:1234/v1/chat/completions`）。地址是本机或局域网的，可以不填 Key。

---

## 4. 开世界

回到「**指挥大厅**」。

1. 点「**启动服务器**」
2. **第一次启动要等 1～2 分钟**，因为要生成地形；以后开就快很多（几秒）
3. 看到服务器卡片变成"运行中"，游戏端口显示 `25565`，就成功了

### 世界设置在哪改

左边「设置」→「🌍 世界设置」：

| 项目 | 说明 |
|---|---|
| 种子 | 留空就是随机世界；填同一个种子会生成同样的地形 |
| 难度 | 和平（没有怪）/ 简单 / 普通 / 困难 |
| 游戏模式 | 生存 / 创造 / 冒险 / 旁观 |
| 运行内存 RAM | 给服务器多少内存。4G 一般够；内存小的电脑填 `2048M` |
| 死亡不掉落 | 勾上之后死掉不会掉东西 |

改完点最下面的「**保存设置**」。

⚠️ **难度和游戏模式保存后，要重启服务器才对当前世界生效**（不是重开世界）。
⚠️ **改了种子，只有点「删除这个世界（重新生成）」时才会用到。**

---

## 5. 开工

还是在「指挥大厅」，每个工人一张卡片，卡片上点「**启动**」。

工人进世界需要几秒钟，然后你会看到：

- 血量 / 饱食 / 兑换点 / TNT / 工具 / 总计：实时数值
- 最近决策：它刚刚在想什么、做了什么
- 底部一行聊天：它和队友说的话

### 一键开全部

左下角有「▶ 一键上班」和「■ 集体下班」，分别是全部启动和全部停止。

### 工人不动怎么办

正常现象，先等一会儿：

- 第一次思考要调用大模型，慢的 10～20 秒，快的 2～3 秒
- 它会原地发呆、来回走两步，那是模型在犹豫

超过 1 分钟完全没动静，去看「帮助」页的错误码说明，或者看「指挥大厅」卡片上的红色报错。

---

## 6. 界面每一页是干什么的

| 页面 | 你在这里能做什么 |
|---|---|
| **指挥大厅** | 开服/停服、看运行日志、看每个工人的状态、开 3D 和思考窗 |
| **工人对话** | 所有工人在公屏上说的话，按时间排 |
| **存档管理** | 看当前世界是什么样、存一份、删除重生成、挑一份存档回到过去 |
| **设置** | 改世界参数、记忆轮数、端口 |
| **AI 大脑供应商** | 填 Key、测连接、拉模型、加自建地址 |
| **工人管理** | 加工人、删工人、改人设、改功能说明书 |
| **帮助** | 常见问题、日志在哪、怎么自己连进来玩 |

### 工人卡片上的按钮

| 按钮 | 作用 |
|---|---|
| 启动 | 让这个工人进世界 |
| 重启 | 卡死了就点它 |
| 停止 | 让它退出世界 |
| **3D** | 开一个小窗口，第三人称看它干活（关掉不影响它工作） |
| **思考** | 开一个小窗口，看它每一步的想法 |
| 人设 | 改它的性格、名字、说话方式 |
| 功能文件 | 改它会做什么事 |
| 删人 | 把这个工人删掉（会先停下） |

> 3D 和思考都是**独立小窗口**，可以同时开好几个。点哪个窗口，哪个就到最前面。

---

## 7. 存档、回档、重开世界

全部在「**存档管理**」页。

### 当前世界（页面最上面）

这里显示的是**磁盘上真实的情况**：难度、模式、世界大小、最后动过的时间、种子。

### 存一份

点「**💾 存一份**」。

- **服务器开着、关着都能存**
- 存的时候不会打断工人干活
- 存完会出现在下面的列表里，标着"手动"

### 自动存档

系统每 **10 分钟** 自动存一份，只保留最近 **5 份**（超出的自动删最老的）。手动存的保留 20 份。

所以就算突然断电，最多丢 10 分钟。

### 回到过去

在列表里找到想要的那个时间点，点「**用这个**」。

程序会先把**现在**的世界存一份（防止你后悔），再用你选的那份替换回去，然后重启服务器。

### 删除这个世界、重新生成

点「**🗑 删除这个世界（重新生成）**」。

它做的事按顺序是：

1. 先把现在这个世界**自动存一份**
2. 停掉所有工人
3. 优雅关掉服务器
4. 把旧世界改名留档
5. 按「设置」里的种子和难度**重新生成**一个新世界
6. 重新开服

所以你点它**不会丢东西**，旧的还在存档列表里。

> 如果只是想换个种子看新地形，就改「设置」里的种子，再来点这个按钮。

---

## 8. 自己进游戏和工人一起玩

1. 服务器先开着（指挥大厅显示"运行中"）
2. 打开 Minecraft 客户端，版本选 **1.21.4**
3. 「多人游戏」→「直接连接」→ 输入：

```
127.0.0.1:25565
```

4. 进服。你会看到几个工人在砍树、搬东西、偶尔在公屏说话

不需要正版账号，不需要联网（这个服务器就在你电脑上）。

**你可以直接跟它们说话**：在游戏里打字，工人能看到并回应。

---

## 9. 怎么正常退出

**别直接点右上角叉号就走。**

正确顺序：

1. 点左下角「**■ 集体下班**」（让所有工人退出）
2. 在指挥大厅点「**停止服务器**」
3. 等提示服务器已停止
4. 再关窗口

直接叉掉的话，程序会尝试帮你优雅关闭（会弹确认），但万一它没处理完，世界可能来不及落盘。

**看到"正在停服 / 正在存盘"就等着，别急着关电源。**

## 10. 出问题了怎么查

### 10.1 先看界面上的报错

工人卡片上出现红字，点开能看到错误码。常见的有：

| 错误码 | 意思 | 怎么办 |
|---|---|---|
| `E_401_AUTH` | 钥匙不对 / 没权限 | 重新复制 Key，去「AI 大脑供应商」点测试连接 |
| `E_NO_PROVIDER` | 还没配任何大脑 | 去填一把 Key |
| `E_429_LIMIT` | 调用太频繁 / 免费额度用完 | 等几分钟，或换个账号/平台 |
| `E_TIMEOUT` | 等太久没响应 | 网络问题，或模型太慢，换个小模型 |
| `E_BAD_RESPONSE` | 模型返回的格式不对 | 多半是模型名填错，检查「型号」 |
| `E_5XX_UPSTREAM` | 平台自己出故障 | 等一会儿再试，或换平台 |

### 10.2 看日志

所有日志在 `logs\` 目录：

| 文件 | 内容 |
|---|---|
| 服务器日志 | Minecraft 服务端输出 |
| 每个工人一份 | 它这一轮的详细过程 |
| 指挥中心日志 | 后端在干什么 |

界面「帮助」页有「打开日志文件夹」，点了会直接跳过去。

把**最后修改时间最新的那个 `.log`** 发给懂的人看，基本就能定位问题。

## 11. 常见问题

**Q：双击没反应，或者闪一下就没了**
A：文件夹没解压完整，或者 `AICraft.exe` 被单独拖出来了。整个文件夹重新解压一次。

**Q：提示缺少 dll / 报错找不到文件**
A：同上，exe 必须和同目录的其他文件在一起。

**Q：工人一直不动，也不报错**
A：① 服务器开了吗？② Key 填了吗？③ 等 20 秒，第一次调用模型慢。④ 点「重启」。

**Q：3D 窗口打开是黑的**
A：工人还没真正进世界。等它卡片上的血量变成数字再开。

**Q：电脑变卡、风扇很响**
A：3D 窗开太多了，每个约占 0.3 GB 内存。关掉几个。或者把「运行内存 RAM」调小一点。

**Q：改了难度 / 游戏模式，进游戏发现没变**
A：保存设置后要**重启服务器**（点停止再点启动），不用重开世界。

**Q：改了种子，世界没变**
A：种子只在**重新生成世界**时生效。想换地形就点「删除这个世界（重新生成）」。

**Q：存档列表里没有我刚才存的**
A：点一下刷新。如果还是没有，看是不是存的时候服务器正在停服（等它停完再存）。

**Q：想把整个东西拷到另一台电脑**
A：整个文件夹拷过去就行。程序自带 Java 和 Node，那台电脑什么都不用装。**但 Key 也在里面，别把这个文件夹发给别人。**

**Q：能开几个工人**
A：看你内存。一个工人加服务器约 2.9 GB，界面左下角有"预计共用运行内存"的提示条，绿的是宽松，黄的要小心，红的建议减人。

## 12. 文件夹里都是什么（别乱删）

```
AICraft\
├─ app\electron-dist\AICraft.exe   主程序（不能单独拿走）
├─ runtime\                        自带的 Java 和 Node（删了就启动不了）
├─ server\                         Minecraft 服务端
│   ├─ world\                      你的世界（很重要，别删）
│   └─ snapshots\                  自动/手动存档
├─ bots\                           工人程序和依赖（node_modules 别删）
├─ logs\                           运行日志（可以定期清）
├─ config.json                     所有配置，含你的 Key（别发人）
├─ config.template.json            配置模板（Key 是空的）
└─ 使用说明书.md / README.md        就是你正在看的这些
```

**可以安全删除的**：`logs\` 里的旧日志、`server\snapshots\` 里不想要的存档（**在界面里删，别手动删文件夹**）。

**千万别删的**：`runtime\`、`app\electron-dist\`、`bots\node_modules\`、`server\world\`。

## 13. 一句话总结

填把 Key → 开服务器 → 点工人启动 → 想回档去「存档管理」 → 想退出先「集体下班」再「停止服务器」。

玩得开心。
