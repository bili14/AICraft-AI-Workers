🎮 AICraft — AI 工人沙盒 · 使用说明
======================================

【这是什么】
AICraft 是一个"AI 角色自己玩 Minecraft"的沙盒。
你不用亲手操作角色——AI 工人（Bot）会在一个 Minecraft 世界里自己砍树、挖矿、
造房子、互相聊天、分工合作。你要做的是当"监工"：启动世界、给每个工人配好
AI 大脑（API Key），然后看它们干活。

──────────────────────────────────────
【三步开始】
1. 第一次玩：双击文件夹里的「创建桌面快捷方式.bat」，桌面会出现 AICraft 图标，
   以后双击图标即可。
   （也可以直接双击「AICraft启动.bat」，或进入 app\electron-dist 文件夹双击 AICraft.exe）
2. 打开后点顶部「启动服务器」。第一次启动请稍等，会自动生成世界。
3. 在工人卡片上点「启动」，工人就进入世界开始干活。

──────────────────────────────────────
【界面导览】
顶部：
  · 暗色 / 亮色：切换深色、浅色界面（护眼，默认深色，颜色柔和）
  · 启动服务器 / 停止服务器：开关 Minecraft 世界
  · 重置世界：删掉当前世界、重新生成（已造的建筑会消失，慎用）
  · 全部启动 / 全部停止：一键开关所有工人

工人卡片（每个工人一张）：
  · ❤ 血量　🍗 饱食　🎟 兑换点　💣 TNT　⛏ 工具　📊 总计：工人的实时状态
  · 最近决策：它刚刚做了什么
  · 对话：它和队友说了什么（上方是最新的，每个工人颜色不同）
  · 启动 / 停止：控制这个工人
  · 👁 3D：打开它的 3D 实时画面（在浏览器里看，不看也不影响它干活）
  · 💭 思考：打开它的"思考流"页面，能看到它每一步前是怎么想的

💡 把鼠标停在按钮上不动，会显示这个按钮是干什么的。

侧边栏：
  · 🌍 世界设置：世界种子（相同种子生成相同地形）、难度（和平=没有怪物 /
    简单 / 普通 / 困难）、游戏模式、死亡是否保留物品
  · 🧠 记忆设置：工人能记住最近几轮对话（数字越大越"记事"，但更慢、更耗额度）
  · 🔌 端口设置：一般不用动，程序会自动避开被占用的端口
  · 改完点「💾 保存设置」，重启服务器 / 工人后生效
  · 🔌 API 服务商：配置 AI 大脑（详见下文）
  · 🤖 添加 Bot：新增工人
  · ❓ 帮助：界面内帮助页

──────────────────────────────────────
【AI 大脑（API / Key）是什么】
工人的"大脑"是云端大模型，需要填一个 API Key（相当于给大脑续费的钥匙）。
  · 程序已预留好几个服务商位置，在「🔌 API 服务商」里填入你的 Key，保存即可。
  · 内置服务商：Agnes（agnes-ai.cn）、阿里云百炼（通义千问 Qwen）、
    火山方舟（豆包 Doubao）、本地 LM Studio。
  · 每个工人可以共用一个 Key，也可以各用各的 Key：
      — 想薅多个免费账号额度 → 每个工人填不同 Key（独立）
      — 用按量付费的 Key → 全部共用一个即可（共用）
  · Key 怎么拿：到对应服务商官网注册账号，在"API 密钥 / API-KEY"页面创建并
    复制，粘贴回程序里保存。

【两种工人预设】
  · 拆建全能工 worker：既会拆（砍树 / 挖矿 / 爆破）也会按蓝图造房子，什么都干，
    新手首选。
  · 纯建造工 builder：专注自主建造。
在「🤖 添加 Bot」里选预设即可一键配置，不用自己研究脚本。

【人设与记忆】
  · 每个工人有一张人设卡（JSON 文件，在 bots\personas\ 目录），决定它的性格、
    说话方式、名字和目标。
  · 想让它扮演不同角色，可以编辑人设卡，或在添加 Bot 时指定另一张。
  · 记忆轮数在「🧠 记忆设置」里调整。

【画面是可选的】
3D 画面只是用来看的。只想看文字、不开 3D 也完全可以，工人照常干活。

──────────────────────────────────────
【常见问题】
  · 双击没反应 / 闪退：确认整个文件夹解压完整，不要只把 AICraft.exe 单独拖出来；
    它必须和旁边的 dll 等文件待在一起。
  · 工人不动 / 报 429 / 额度不足：免费额度用完或 Key 填错，换一个 Key 或服务商。
  · 👁 3D 打不开：先确认该工人已经点了「启动」（它进世界后才有画面）。
  · 端口被占：程序会自动顺延端口；真遇到冲突可在「🔌 端口设置」改。
  · 想拷到别的电脑：整个文件夹拷过去即可。程序自带运行环境，
    支持 Win10 / Win11 的 64 位系统，无需另装 Node、Java。

【目录说明】
  · app\electron-dist\AICraft.exe：主程序（别单独移动，要和旁边的 dll 一起）
  · runtime\：自带的运行环境，勿删
  · server\：Minecraft 服务器和世界存档
  · bots\：工人脚本、人设卡 personas\、依赖 node_modules（勿删）
  · config.json：全部配置（一般在界面里改，不用手动编辑）
  · logs\：运行日志，出问题时可查看

祝玩得开心。
