# 干净机 Smoke 清单（20 项）

> 用法：发行包拷到一台**从未装过 AICraft 的 Windows 机器**上逐项过。任何一项不过 → 回开发机修完重打。
> 环境要求：Windows 10/11 64 位、未装 Node/JDK（验证便携运行时自带）、已关杀毒软件或已加信任目录。

## 一、解包与首启（1~5）
1. [ ] 整个文件夹解压到短路径（如 `D:\Games\AICraft`），无中文/空格路径警告。
2. [ ] 双击 `AICraft.exe`，**1 秒内**见到挖掘加载画面（不灰窗、不白屏）。
3. [ ] 蓝窗 SmartScreen 提示时，「更多信息→仍要运行」可走通（文案在使用说明里有）。
4. [ ] 若杀软拦截 java/node，把整个目录加信任后重开能起。
5. [ ] 首启向导自动弹出（`needsKey=true` 或 `noWorld=true`），不直接进大厅。

## 二、首启向导与世界生成（6~10）
6. [ ] 向导 Step1 环境自检显示「自带 Java 就位」（runtime.java=portable）。
7. [ ] Step2 填一个真实 key → 点「测试一下钥匙」→ 绿对号「通了」。
8. [ ] Step3 世界设置：种子留空=随机、难度和平、生存、死亡不掉落默认开。
9. [ ] Step4 点「开始上班」→ MC 首生世界，**90~180 秒内**进入「服务器就绪」（记录实际耗时）。
10. [ ] 大厅顶部服务器卡片显示「运行中」，server.phase=running。

## 三、bot 进厂与 LLM 通路（11~15）
11. [ ] 点「一键上班」或 `/api/bot/preset/two` → worker + builder 两个 bot 自动添加。
12. [ ] 两个 bot 在 60 秒内 spawn 进世界（大厅卡片绿点，meta.spawned=true）。
13. [ ] bot 开始砍树/盖房，思考流页（内心戏）有 JSON 决策流刷新。
14. [ ] 故意填错一个 key → 对应 bot 卡片飘红，错误条显示「大脑钥匙不对」（E_401），不显示英文原文。
15. [ ] 6 bot 同开（手动加够），共享冷却生效：故意造 429，同 provider 所有 bot 集体放慢。

## 四、回环与安全（16~18）
16. [ ] 另一台机或用 `netstat -ano | findstr "3001"` 确认 3001/3002/3100 只监听 127.0.0.1，外网不可见。
17. [ ] `GET /api/config` 返回的 key 字段全是 `****`，看不到真实 key。
18. [ ] `GET /api/hall` 不包含任何 provider.key 原文。

## 五、存档与停服（19~20）
19. [ ] 点「立即存一份」→ 快照五步走完（约 5~15 秒），存档列表出现新条目，sizeMB>0。
20. [ ] 点「集体下班」→ 5~15 秒内优雅停服（不黑窗、不任务管理器强杀），latest.log 有 Saving/Stopping 段；重开世界不丢。

---
**全部 20 项打勾 = 发行包干净机验收通过。**
任一项失败：记录实际现象 + 截图（大厅卡片红条 / 日志尾 20 行），回开发机修。
